# GBS — True Cost Per Mile Dashboard

An interactive Streamlit application designed for logistics operations and fleet management. This dashboard unifies operational cost data—including fuel, driver pay, maintenance, and tolls—into actionable cost-per-mile analytics.

---

## Features

- **Executive Overview:** High-level metrics showing baseline fleet costs, optimization targets, and projected annual impact.
- **Cost & Fuel Analytics:** Itemized breakdowns of cost drivers and fuel composition metrics.
- **Fleet & Route Performance:** Visual comparison of performance across specific trucks and shipping lanes.
- **Maintenance Tracking:** Status indicators for overdue, upcoming, and scheduled vehicle service.
- **Interactive Control Panel:** Embedded parameter controls to adjust scenario modeling in real time.
